# v0.1.0 · 首个公开预览版

My Monitor 是一款本地桌面数值监控工具：从网页选取实时数据，用告警检查范围，再把进度与变化放在半透明置顶浮窗中。

## 主要功能

- 网页选取与固定数值，可选总量数据；数据卡片 / 列表、分类统计、暂停 / 恢复。
- 变量 / 定量检测，记录倍率、通知开关、范围数轴和最近 10 / 20 / 50 次图表。
- 默认 20 × 300 px 浮窗，最近变化量可视化、瞬时变化量文字、零变化开关、平滑动画与位置记忆。
- 六套配色、中文 / 英文、启动浮窗、开机自启与托盘快捷操作。
- 本地凭证保护、请求及网页资源限制、失败退避与通知合并。

## 下载与运行

平台：**Windows x64**。下载附件 `MyMonitor-v0.1.0-windows-x64.zip`，完整解压后运行 `MyMonitor-win32-x64/MyMonitor.exe`。不要仅复制 exe；GitHub 自动生成的 Source code 压缩包是源码，不能直接运行。

使用附件 `SHA256SUMS.txt` 核对 ZIP 的 SHA-256。程序目录需要放在固定位置，开机自启会记录 exe 路径。

首次启动默认打开浮窗；以后按用户保存的设置。关闭主窗口保留托盘运行，真正退出使用托盘“退出”。

## 注意事项

- 首次公开预览，没有安装器、签名或自动更新；Windows 可能显示未签名程序提示，请先核对下载来源和校验值。
- 网页自主更新档位不主动重载；网站不自动刷新时可能读到原值。第三方认证与页面兼容性取决于网站。
- 每次开始告警会重置记录；停止保留图表。重启或运行中采集失效会开始新段。
- 密集越界事件会合并为系统通知摘要；通知依赖 Windows 权限和勿扰模式。
- 数据目录 `%APPDATA%\my-monitor\` 含敏感登录资料，不能随 Issue 上传；软件退出期间不持续监控。
- 仅 Windows x64 验证。磨砂风格通过半透明表面呈现，不对其他原生窗口进行系统级背景模糊。
