# v0.2.0 · 网页兼容性与待机优化

新增可选的低占用模式，放宽默认网页读取限制；修复浮窗更新抖动，并减少主界面、浮窗和闲置网页的后台内存开销。

## 新增与调整

- **低占用模式默认关闭**：原有严格网页请求、流量、CPU / 内存预算由设置页开关控制。开启后可能限制部分网页访问、登录或更新。
- **19 项资源阈值**：测试模式下可调整请求与流量、CPU / 内存、窗口 / 会话、并发和超时设置；保存后生效。退出测试模式只隐藏阈值，不撤销已保存的模式和设置。
- **后台界面减负**：隐藏 / 最小化主界面停止重绘及动态预览；重新显示同步最新数据，采集和告警继续运行。
- **精简浮窗更新**：只传递显示数据，不复制告警图表及来源网址。
- **安全回收闲置网页**：定时重载网页完成采集、隐藏并空闲约 15 秒后，在安全条件满足时释放窗口，下次采集重新加载。实时网页、可见登录 / 选取窗口、页面会话数据、跨站导航历史及活跃 Worker 会阻止回收。
- **空待机回收**：没有启用中的数据源、浮窗关闭、没有剩余网页窗口且主界面隐藏到托盘约 15 秒后，释放无未保存内容的主界面。重新打开恢复页面、筛选和窗口位置；编辑草稿与未保存设置保持原窗口。

## 修复

- 修复数据更新时浮窗宽高的像素级抽动，避免 Windows DPI 舍入与重复尺寸计算相互触发。
- 浮窗复用现有行节点，数值更新不反复移动行；保留 300 ms 平滑进度动画。

## 下载与升级

平台：**Windows x64**。下载 `MyMonitor-v0.2.0-windows-x64.zip` 和 `SHA256SUMS.txt`，校验后完整解压。GitHub 自动生成的 Source code 压缩包是源码，不能直接运行。

从 v0.1.0 升级：

1. 使用托盘菜单“退出”，不要仅关闭主窗口。
2. 备份 `%APPDATA%\my-monitor\` 到自己控制的安全位置；该目录包含敏感登录资料，不要上传。
3. 将新版本完整解压到新目录，运行 `MyMonitor-win32-x64/MyMonitor.exe`；不要只替换 exe。
4. 沿用 AppData 的数据源、告警及偏好。旧配置缺少低占用模式字段时默认关闭；希望沿用原来的严格预算，请主动开启低占用模式。
5. 若启用了开机自启，软件路径变动后关闭再开启该选项，以更新启动路径。

无需手动编辑配置。旧版不识别新增资源偏好；降级前保存独立备份，不承诺新旧版往返保留全部新增设置。重启时，运行中的告警会按原规则从新段记录。

## 注意事项

- 低占用模式关闭可能增加网页网络和内存消耗。来源数量、任务并发 / 取消 / 超时、HTTP 接口预算、凭证加密、权限与 IPC 校验仍保留；不是无限制访问模式。
- 资源阈值只在低占用模式开启时参与网页预算控制，退出测试模式不会关闭低占用模式。
- 后台回收独立于低占用模式。需要保留会话的网页、活跃 Worker 和未保存的编辑界面会保留，因此降幅随网页和系统环境变化，Electron 基础进程仍占内存。
- 网页自主更新不强制重载，网站不自行更新时可能读到原值；第三方 OAuth、验证码与页面兼容性仍取决于网站。
- 文件夹分发，无安装器、签名或自动更新。使用可信仓库下载并校验；不要移除系统防护。
