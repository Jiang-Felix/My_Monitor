# My Monitor 使用说明

[返回 README](../README.md) · [更新记录](../CHANGELOG.md)

本文适用于 0.1.0 Windows x64 预览版。界面默认使用简体中文，“设置”中可切换英文；这里用中文名称描述操作。

## 数据：连接你的数值

### 网页选取

1. 点击“添加数据源”，填写名称、显示单位、数据源网址。
2. 实时数据来源选“网页选取”，点击“选取实时数据”。在新窗口中正常登录目标网站，包括站点要求的二次认证。
3. 将选取提示面板拖到不遮挡内容的位置，必要时折叠；启用选取后点击目标数值所在的文字元素。选取单个可解析数值，不要选择整张表、输入框或包含多个数值的容器。
4. 如需进度比例，给总量数据选取同一网页上的元素，也可以填写固定数值；无需总量时选择“不设置总量数据”。
5. 设置更新频率，点击“测试读取”。确认读取结果和单位含义后保存。

提示面板的“取消”或关闭选取窗口会结束选取，你可以重新打开；未保存的数据源编辑取消后会清理临时登录资料。已保存数据源的登录资料保留在其本地独立分区，不同数据源不自动共享登录状态。

优先选择有稳定标识的元素。页面改版后，可从数据卡片的 `…` 进入编辑，重新选取。浮窗名称标签使用名称的第一个字符，所以可用一个易识别文字或符号开头。

**选取限制：**目前按 DOM 文字与 CSS 选择器读取，不支持跨域 iframe、Shadow DOM、图片 / canvas 数字识别。弹窗登录有支持，但第三方 OAuth 服务可能禁止嵌入式浏览器，Google 登录并非对所有网站都可用；遇到拒绝登录不要复制系统浏览器的 Cookie 来绕过。

### 固定数值与总量数据

网页来源中的实时数据和总量数据均可独立设置为“固定数值”。例如：实时数据取自网页，总量数据填套餐上限 `100`。固定数值只在你修改配置时变化；它仍按设置周期参与记录。

输入框只填写数字，单位单独填写；支持 0、负数和小数，但总量数据必须符合配置校验。两项都为固定数值时无需网页网址。单位仅用于显示，不会自动进行 GB / MB 或币种换算。

实时数据大于总量数据时监控失败，卡片显示原因；失败样本不会覆盖最后有效样本。没有总量数据时显示独立数值，不计算比例。

### 更新频率

常规模式提供离散滑条：

| 档位 | 时间 | 网页行为 |
| --- | --- | --- |
| `1s` / `30s` | 1 秒 / 30 秒 | 网页自主更新：复用已打开页面，读取 DOM，不强制重载 |
| `1min` / `10min` / `30min` | 1 / 10 / 30 分钟 | 按周期重新加载网页 |
| `1h` / `5h` / `12h` | 1 / 5 / 12 小时 | 按周期重新加载网页 |
| `1d` / `1w` / `1m` | 1 天 / 7 天 / 30 天 | 按周期重新加载网页 |

绿色档位表示轻量的网页自主更新模式。**网站若不自行更新页面，1s 读取也只会读到原值。** 定期重新加载会有网页请求及加载成本，建议先从 1 分钟或更长开始。网站限流或失败时，软件会延长重试等待；实际采集间隔可能大于设置值。

### 卡片、列表和状态

“卡片 / 列表”切换只改变布局。全部 / 监控正常 / 监控异常按钮显示分类数量；“监控异常”包含手动暂停、无有效样本、过期、登录失效、网络、解析及范围错误。

每个数据源右侧：

- `…`：直接编辑配置；登录窗口、浏览器打开和删除等操作放在编辑页面内。
- 红色方块：暂停监控；绿色三角：恢复监控。暂停不会删除已保存的登录资料。

鼠标悬停无文字按钮可查看提示。失败时保留旧值并标明状态、错误原因与最后成功读取时间。删除数据源会级联删除相应的告警条目和记录，确认提示会说明影响。

## 告警：范围与连续记录

### 创建与检测类型

点击“新增告警”，填写名称、选择数据源与类型，设置下限 / 上限。至少填写一侧边界，另一侧留空表示不限制；上下限均包含边界。

| 类型 | 被检测的量 | 示例 | 图表 |
| --- | --- | --- | --- |
| 变量检测 | 本次记录值 − 上次记录值，带正负号 | 范围 `-2 ~ 4`：差值 5 或 -3 越界；4 在范围内 | 直方图 |
| 定量检测 | 本次记录的实时数据 | 范围 `20 ~ 80`：数值 81 越界；80 在范围内 | 折线图 |

变量检测第一次记录只建立基准，不告警；定量检测第一次有效记录即检查范围。每个越界记录均产生告警事件，提醒后不改变记录节奏。

### 记录倍率

常规模式使用 **1×–12×、步长 0.5×** 的滑条，表示平均每多少次数据源成功更新记录一次。下方实时显示对应的近似时间频率。

例如数据源每 60 秒更新：`1×` 约每 1 分钟记录，`2×` 约每 2 分钟记录；`1.5×` 通过交替等待 2 次、1 次更新实现平均倍率，约每 1.5 分钟一次。这不是额外的采集定时器，不会因增加告警再发一轮网页请求；网络延迟和失败会影响实际时间。

### 四个操作按钮与分类

右侧 2 × 2 按钮分别为：编辑 `…`、停止 / 开始、展开 / 收起图表、通知开 / 关。图表按钮按类型显示直方图或折线图，编辑页面提供删除。

分类含义：

- **活跃告警**：正常检测，通知开启。
- **静默告警**：正常检测，通知关闭；仍按相同规则计算、记录越界与显示图表。
- **暂停告警**：已停止，或数据源 / 计算状态无法正常检测。
- **全部**：以上所有条目。越界是正常检测结果，不会单独归入暂停告警。

停止只暂停记录，保留图表；**每次开始都会清空旧记录**并建立新段。软件重启、运行中采集失败 / 过期或数据源暂停等中断后，会从新一段开始，避免跨越中断计算变化量。软件退出期间不记录。

### 数轴、图表与通知

数轴值域包含最近 5 次检测值，以及你设置的完整上下限。坐标刻度取合适的整数，边界和检测值标注仍保留精确值。

图表分别可选最近 10 / 20 / 50 次，默认 20，内存与本地保存的图表点最多保留最近 50 次；窗口选择按条目保存。超过选择数量的点不会继续显示，也不是长期历史记录库。可悬停或聚焦图中点查看精确数值。

密集越界通知会合并成约每 2 秒一次系统摘要，事件仍记录；最近通知回执最多保存 200 条，条目显示最近越界情况。Windows 勿扰模式、通知权限与系统策略可能影响实际弹出，“请求已接收”不等于用户一定看到了通知。通知关闭只抑制系统通知，其他检测逻辑不变。

## 浮窗：进度与变化

浮窗置顶且不出现在任务栏，拖动边缘移动，按 Esc 关闭。位置按显示器工作区约束并保留间距；重启恢复最后位置，显示器变更后会修正。

首次启动和恢复默认的进度条尺寸为 **20 px 高 × 300 px 宽**。默认开启名称标签、实时数据、总量数据、单位、百分比、最近变化量可视化、瞬时变化量数值和平滑移动；仅“显示零变化”关闭。

| 设置 | 含义 |
| --- | --- |
| 名称标签 | 在左侧显示数据源名称首字符 |
| 实时数据 / 总量数据 | 显示当前数值；总量数据后缀需先开启实时数据显示 |
| 单位 | 数值 / 总量数据右侧只显示一次单位，没有空格，例如 `36.5/100GB` |
| 百分比 | 有有效总量数据时显示比例，没有时显示 `--` |
| 最近变化量可视化 | 增加 / 减少使用各自颜色，保留最近一次非零变化；零变化更新不会清除上次可视化 |
| 瞬时变化量数值 | 本次成功更新与上次成功更新的差值，零变化默认不显示 |
| 显示零变化 | 开启瞬时变化量数值后可调整，开启则显示零差值 |
| 平滑移动 | 进度变化和增减状态切换在 0.3 秒内平滑完成 |
| 文字对齐 | 居左、居中、居右、分散；默认分散，数值左、变化量右 |

变化量文字例如 `+2/1分钟`，不带该数值的单位，时间分母使用数据源**设置的更新周期**，不是实测的两次读取耗时。合并显示时数量与变化量之间为两个空格，例如 `36.5/100GB  +2/1分钟`；分散模式把两部分放在两端。

高度范围 4–80 px，宽度范围 120–640 px。开启任一条内文字显示时高度至少 16 px；如果先调细再开文字，会自动提升至文字可读下限。浮窗名称和百分比区域另占宽度。

可调整面板颜色 / 透明度、轨道、填充及增减颜色。右侧预览有常规、无总量、增加、减少四个样例，动态演示增减；保存后应用到实际浮窗。保存 / 恢复默认位于预览下方；浮窗视觉恢复默认不会重置“设置”中的用户启动偏好。

## 设置与托盘

支持深海蓝、石墨灰、松林绿、暮光紫、云雾白、暖沙色六套配色，以及简体中文 / English。语言按钮显示将切换到的语言。

- **启动时打开浮窗**：首次默认为开启，之后每次按用户保存的选择执行。
- **开机自启**：默认关闭，在已打包 Windows 程序中可启用。移动软件目录后应关闭再开启，更新启动路径。
- **托盘单击切换浮窗**：默认开启；为区分双击有短暂判定时间。
- **托盘双击打开主界面**：默认开启；与单击开关分别保存。
- **测试模式**：每次启动默认关闭。开启后以不同样式显示高级选项，恢复 HTTP 接口入口、CSS 选择器、等待时间、原始周期输入和下拉菜单等调试 UI。

托盘图标随浮窗状态在 mini-c / mini-w 之间切换，主界面左上角图标同步。右键菜单可以打开主界面、切换浮窗、刷新全部和退出。`Ctrl+Alt+M` 可打开主界面；如果快捷键已被其他软件占用，则无法注册。

关闭主窗口会最小化到托盘并继续采集；要真正退出，请使用托盘“退出”。

## 测试模式中的 HTTP 接口

仅测试模式显示添加 HTTP 数据源入口；关闭测试模式后，已配置的 HTTP 数据源仍可正常运行。

支持 **GET + JSON + Bearer Token**；对象路径如 `data.used`，数组路径如 `data[0].balance`。优先使用 HTTPS，仅本机测试允许 localhost 的 HTTP。不支持任意 POST、Cookie 粘贴或自定义请求头。重定向不自动跟随，避免把授权发送到别的地址。

先“测试读取”再保存。编辑时 Token 留空表示保留已保存凭证；可选择清除；改变协议、域名或端口后会清除旧凭证，需要重新填写。不要把 Token 放进网址；敏感参数只在能够识别时遮盖和加密。

测试模式可自填更新次数 / 周期。告警自定义更新次数需为 1–2592000 的整数，1–12 内同时允许半档倍率；不在常规滑条范围内的旧设置会保留，需明确调整后才改变。

## 本地数据与备份

数据目录通常为 `%APPDATA%\my-monitor\`，主配置为 `monitor-state.json`，有效旧版本备份为 `.bak`；包含来源配置、最后有效样本、用户偏好、有限告警记录及网页登录资料。退出软件后备份整个目录到你控制的安全位置。加密凭证绑定系统用户，跨电脑 / Windows 用户复制不保证能够解密，可能需重新登录。

一般采集记录采用约 5 秒合并写入，配置更改及时保存；退出会尝试完成写入。断电或强制结束可能丢失最近几秒记录。读取失败 / 解密失败时应用保护原文件并进入只读状态，不应直接删除损坏文件以“修复”。先完整备份，确认 `.bak` 有效后，在软件退出时恢复；不要把这些文件附到公开 Issue。

更新软件：先从托盘退出，完整解压新版本到新目录，启动新版本；用户数据仍在 AppData，不需要复制到 exe 旁。启用了开机自启时，更新路径后关闭再开启该选项。配置格式改变时按对应 Release 的迁移说明操作，降级前保存独立备份。

## 常见问题与资源使用

| 现象 | 检查方式 |
| --- | --- |
| 值保持不变 | 1s / 30s 模式下网站是否自行更新？是否选到了固定文字？用更长的重新加载档位检查 |
| 登录过期 / 找不到元素 | 编辑中打开登录窗口重新认证，再重新选取；有验证码时人工完成 |
| “实时数据大于总量数据” | 检查选取目标、单位含义和固定总量是否正确，不要用软件显示单位来做换算 |
| 没有弹出通知 | 检查喇叭开关、条目是否正常检测、Windows 通知和勿扰模式；首次变量记录只有基准 |
| 图表重置 | 检查是否点击开始、重启程序或发生采集失败 / 过期等中断 |
| 网页被保护性停止 | 检查网站频繁请求、大体积资源、CPU 或内存占用；减少网页来源及频率，避免监控视频 / 无限刷新页面 |

最多配置 100 个数据源和 100 个告警；网页父窗口及弹窗合计最多 8 个，网页并发读取 2 个，HTTP 并发 4 个。实际合适数量随网页体积和机器性能变化，建议先从少量来源开始。

网络保护包括请求速率、响应体大小、网页每来源与全局流量额度；网页保护还会检查内存和 CPU。保护发生时关闭对应页面并报告失败，不会为了继续采集无限创建窗口或请求。应用层限制不是系统级流量整形，个别突发下载仍可能超过一个检查周期的预算；浏览器服务可能有自己的背景请求。

不要使用此预览版承担必须 24 小时连续运行或不能漏报的监控任务。它不会绕过网站验证或访问限制。安全信息和漏洞报告方式见 [SECURITY](../SECURITY.md)。
